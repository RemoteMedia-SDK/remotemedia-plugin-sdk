## 2. Host (remotemedia-sdk-base)

## 3. Migrate generators
Each item: declare `generates` and a strategy, stop work that runs outside the call future (token or `on_cancel`), apply both dispositions to the node's own state (an LLM keeps or rolls back the cut-off reply; a TTS node discards its queued text by default; an S2S node retains buffered audio), and add `assert_generator_cancels`. Paths are relative to `D:\rm-mp`.

### 3.1 Built-in Rust (remotemedia-sdk-base/src)
- [x] 3.1.1 `OpenAIChatNode` and `MultimodalLLMNode`: text, `DropStopsWork`; the chat backend keeps a cut-off reply in history, marked interrupted, when partial output is retained, and rolls it back otherwise (two tests against the mock SSE provider).
- [x] 3.1.2 `HostedTurnNode`: text, `OnCancel` (its calls only queue commands; `on_cancel` interrupts the running turn, test `on_cancel_stops_the_running_turn`); its barge publication carries dispositions (2.4).
- [x] 3.1.3 `TestToneTtsNode`: audio, `DropStopsWork` (it renders at once, so nothing outlives a call; a token check inside its synchronous loop could never fire); discards queued text by default.
- [x] 3.1.4 `PythonStreamingNode` factories (Kokoro, VibeVoice, CosyVoice3, Voxtral, LFM2Audio): the role comes from the Python class's `META:` at initialization; the classes are migrated (3.2).

### 3.2 Python nodes (remotemedia-sdk/clients/python/remotemedia/nodes)
All migrated nodes derive `(<Modality>Generator, MultiprocessNode)`; their tests are model-free, through the real worker loop with stand-in models (`tests/test_generator_migration_{tts,s2s,text,moss,motion}.py`, 90 tests; remotemedia-sdk e404b1e7..8d6727ed). Real models, through the worker loop with `remotemedia.testing.assert_generator_cancels` (CPU, cached weights, offline): `KokoroTTSNode` baseline first audio 0.48 s, 0.77 s after `INTERRUPT`, 0.80 s after `ABORT`; `LFM2AudioNode` (LFM2-Audio-1.5B, text input) baseline 0.38 s, 0.36 s after `INTERRUPT`, 0.34 s after `ABORT`, no late output, pending input kept under `INTERRUPT` and dropped under `ABORT`. `LFM2TextNode` and `LFM2InstructAgentNode` (LFM2-350M) answer in one piece, so they were cancelled at 30 % of the baseline (10.8 s and 6.9 s) instead: the cancelled call emitted nothing and the next call was not held up by the abandoned generation (first text 10.8/10.7 s; the agent's next call ended in 1.3 s after `INTERRUPT`, declining to answer with the cut-off reply in its history, and answered in 6.9 s after `ABORT`). Not run (dependency or model not on this machine): the MLX nodes, `KokoroOnnxTTSNode`, `VibeVoiceTTSNode`, `CosyVoice3TTSNode`, `VoxtralTTSNode`, `NeuTTSNode`, `IndexTTS25Node`, `HermesLLMNode`, the Moss nodes (`MossTTSRealtimeNode`'s vendored model imports `transformers.initialization`, which the local transformers lacks; its plugin venv pins its own), motion nodes.
- [x] 3.2.1 Nodes with a barge latch, now routed through one stop shared by the legacy `barge_in` and `cancel()`: `KokoroTTSNode`, `KokoroOnnxTTSNode`, `QwenTTSMlxNode` (TTS: `OBSERVES_TOKEN`, discard pending input by default), `LFM2AudioNode` (`OBSERVES_TOKEN`; retain marks the cut-off turn interrupted, discard rolls back the turn; its early-interrupt rollback is its `default_disposition`, < 3 s), `LFM2AudioMlxNode`, `PersonaPlexAudioMlxNode` (`DROP_STOPS_WORK`, inline steps), `QwenTextMlxNode`, `MlxLmTextNode` (`OBSERVES_TOKEN`). `Interruptable`/`StatefulConversation` are deprecated (warn on import and subclassing). Limits: kokoro-onnx's own background batch finishes (only emission stops); the `LFM2AudioMlxNode` rollback relies on mlx_audio's ChatState growing by reassignment (not verifiable without mlx); `PersonaPlexAudioMlxNode` discard resets its whole streaming context.
- [x] 3.2.2 `VibeVoiceTTSNode` (the token sets its `stop_event`), `CosyVoice3TTSNode`, `VoxtralTTSNode` (a running vLLM `generate()` finishes; its result is discarded), `NeuTTSNode`, the Moss nodes (a `StoppingCriteria` where the remote model's `generate` accepts one, else one `generate()` finishes and is discarded; a lock keeps it from overlapping the next call), `MossTTSRealtimeNode` (discard resets the whole session), `IndexTTS25Node`, `LFM2TextNode`, `LFM2InstructAgentNode`, `LFM2DemoAgentNode` (generation moved off the event loop with a token-polling `StoppingCriteria`; tool side effects are not undone on discard), `HermesLLMNode` (`ON_CANCEL`; on the attach path Hermes may still finish remotely).
- [ ] 3.2.3 Legacy `Node`-based generators `Qwen2_5OmniNode`, `UltravoxNode`, `TransformersPipelineNode`: not migrated (a rewrite, a keyword-argument example and the legacy session-state API, and mostly non-generative tasks respectively); their modules are marked deprecated, non-cancellable generators.
- [x] 3.2.4 Motion: `KimodoMotionNode`, `ArdyMotionNode` (`OBSERVES_TOKEN`; discard restores the anchor and drops the call's cache entry; ARDY office mode runs each exchange as its own task — a worker-committed horizon cannot be withdrawn, and a cancel in the very first exchange can drop the one-time `motion_capabilities` message), `HomeLifeNode` (`DROP_STOPS_WORK`; discard restores the planner state, pending discard clears the queue).
